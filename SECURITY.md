# Security policy

## Supported versions

Only the latest published release line receives security fixes. The package is not
production-ready until a stable 1.x release is explicitly published.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not publish a
security-sensitive issue, uploaded dataset, credential, or exploit proof publicly.

For local-development reports where private reporting is unavailable, contact the
repository maintainer privately and include affected version, reproduction steps, and
impact without attaching real production data.
